
# Travel Brief SEA

Travel Brief SEA is an AI-powered travel brief generator for Southeast Asia that helps users get an initial travel overview based on country, trip duration, travel month, budget, and traveler style.

## Features

The MVP generates concise travel briefs including:

- Quick summary
- Weather and timing notes
- Estimated budget
- Recommended areas
- Common mistakes
- Initial checklist
- Suggested mini route

## Supported Countries

- Thailand
- Vietnam
- Indonesia
